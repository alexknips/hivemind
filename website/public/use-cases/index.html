What it does today

Shipped

Every write is attributed and append-only. Status (proposed · accepted · contested · superseded) is derived from the graph, never hand-set.

Shipped

Capture the decision in-flow

Agent
Mid-task, your agent records the choice, the options it weighed, and why — without leaving the session.

capture_decision(title, rationale, options, chosen)
Shipped

Ask "why did we choose this?"

Human · Agent
Reconstruct any past decision at query speed — cited to real records, not a summary of a chat log.

hivemind query recall "why sqlite for local?"
Shipped

Disagreement stays on the record

Human · Agent
Push back on a decision and both sides are kept. It becomes contested — a queryable state, not a lost thread.

hivemind disagree --decision <id> --reason …
Shipped

Supersede without erasing

Human · Agent
Replace an old decision; the original and the full chain remain, walkable back to the first proposal.

hivemind supersede --old <id> --title …
Shipped

Review a week of agent decisions

Human lead
Govern agent work after the fact — approve, dispute, or supersede — at query speed. No watching agents live.

hivemind review --actor 'agent:*' --since 7d
Shipped

Turn existing notes into decisions

Human

Where it's going

Planned

On the roadmap, in the open. Shown here as intent, not as something that exists yet.

Planned · M4

Cite living documents as evidence

Link decisions to Confluence and Google Docs, resolved to the version at citation time — so evidence stays honest as the source moves.

Planned · M5

Two projects, quietly diverging

Two teams each make a reasonable call in parallel — and one silently breaks an assumption the other is building on. Nobody notices for weeks. HiveMind derives the premises behind each decision so the divergence surfaces early, while it's still cheap to reconcile.

Planned · M6

Daily memory that replaces the wiki

A capture plugin that just runs inside your coding agent all day — decision memory becomes a habit, and the stale wiki fades away.

Planned

Fly through decisions over time

A temporal view of the graph — watch options, evidence, and supersessions accrete along a real timeline, not a static diagram.
